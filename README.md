# One-page customer sites (public)

Each folder is one customer's one-page website, served by GitHub Pages at
https://aaronreddix1987-sketch.github.io/sites/FOLDER/ . Folders named `sample-*` are made-up businesses used as demos.

Build a site: `python3 _tools/build.py intake.json FOLDER`. No secrets or customer contact data other than what appears on the customer's own public page belong in this repo.
